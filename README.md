# 铁甲对决 · 3D 坦克对战

War Thunder（战雷手游）风格的网页 3D 坦克对战，单文件实现，不依赖服务器、不联网也能玩。

## 玩法

- **左下摇杆**：开车
- **屏幕其余任何地方拖动**：转炮塔（镜头跟着走）
- **右下红圈**：开火
- **左侧大圆钮**：切穿甲 / 高爆弹
- **右侧竖排**：视角、狙击镜、陀螺仪、音效
- **左上方圆盘**：小地图雷达

## 怎么打开

下载 `index.html`，用浏览器打开即可。手机上如果浏览器不允许打开本地 HTML，就用 GitHub Pages 的在线版。

## 技术

- Three.js r160（内联，无 CDN 依赖）
- 单文件约 800KB，程序化建模与音效，无外部素材
- 触屏与键鼠双支持，陀螺仪瞄准，狙击镜带密位刻度
